# Xavier Sylvers - Portfolio

Aspiring AI Solutions Analyst portfolio built with Next.js and Tailwind CSS.

## Overview
This portfolio highlights projects focused on AI workflow automation, applied AI solutions, productivity tooling, and modern technology consulting. The site is designed to be professional, clean, and forward-looking.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Static Export (GitHub Pages ready)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment (GitHub Pages)

This project is configured for static export (`output: 'export'` in `next.config.ts`).

To deploy to GitHub Pages:
1. Build the project:
```bash
npm run build
```
2. The static files will be generated in the `out` directory.
3. You can deploy this `out` directory to GitHub Pages using a GitHub Action, or push the contents to a `gh-pages` branch.

**Note**: Since image optimization is disabled for static export, all images should ideally be optimized before placing them in the `public` folder.
